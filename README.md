🚀 ProManager
A simple Task Management Web Application built using React, TypeScript, Node.js, Express, and MongoDB Atlas.

✨ Features


User Authentication


Create & Manage Projects


Task Management


MongoDB Atlas Integration


Responsive UI



🛠️ Tech Stack


React.js


TypeScript


Node.js


Express.js


MongoDB Atlas


Mongoose



⚙️ Installation
Clone Repository
git clone <repository-url>cd Task_Management

Install Dependencies
npm install

Create .env File
MONGODB_URI=your_mongodb_connection_urlJWT_SECRET=your_secret_key

Run Project
npm run dev

✅ Output
MongoDB Atlas ConnectedServer running on http://localhost:5000
